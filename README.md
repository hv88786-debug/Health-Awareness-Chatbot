## 📌 Problem Statement

Healthcare awareness remains limited for many people, especially in rural and semi-urban areas. People often ignore symptoms or search unreliable information online.

This project aims to provide:

* Symptom awareness
* Preventive guidance
* Health education
* Risk awareness
* Responsible healthcare recommendations

## 🧠 How It Works

1. User enters symptoms.
2. The chatbot analyzes keywords.
3. Multi-word matching is performed.
4. Symptom combinations are checked.
5. Risk score and severity level are generated.
6. Preventive guidance is provided.
